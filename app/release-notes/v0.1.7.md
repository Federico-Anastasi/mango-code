Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.7_x64-setup.exe`) and run it. If you have 0.1.1, 0.1.2, 0.1.4 or 0.1.5, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models.

**Changed since 0.1.5**

Your computer
- Integrated graphics that was given 8 GB of memory or more, as on a Ryzen AI Max, is used as a graphics card. With less, the models run whole on the processor, which has the rest of the memory.
- On a computer without a graphics card the model proposed is one that writes at reading speed on the processor, not the largest that fits in memory.
- A model that cannot run on your computer says so in one sentence, without the technical detail.
- A model whose engine needs AVX2 is not proposed on a processor without it.

Fixed
- Making a picture no longer changes the model that writes: every conversation stays on its model.
- A file the agent changes keeps its line endings: one with Windows line endings stays so.
- Search in the project works also when the app is started from a PowerShell 7 terminal.
- A picture or a command interrupted by closing the app shows as stopped at the next start, instead of running forever.
- At startup the default model waits for the update of its engine, instead of another model taking its place.
- The space used by the models counts the files you put in the models folder by hand.
- The installer of an update no longer stays in the temporary folder.
- The programs the agent starts through the PowerShell of the Microsoft Store end when the app quits, or at its next start if it was closed by force.
- "Preparing the conversation" appears once while the model works.

Libraries
- The libraries of the agent and of the interface are updated: none with a known vulnerability of high or critical severity is left in what is installed.
- The agent no longer carries the libraries of 19 cloud providers the app does not offer.

For programs that use Mango Code
- A request with the header `X-Mango-Side-Request` is not a conversation's: the model it names takes the engine for a while, and the conversations stay on the model they had.
- While such a request has the engine on another model, the state of `GET /engine` has `conversation_model`: the model the conversations stay on.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- Integrated graphics used as a graphics card was not tried on a real computer: if you have one, tell us how it goes.
- Pictures were tried on NVIDIA cards of 8 GB (10 to 20 seconds a picture on an RTX 3060 Ti) and of 4 GB (one to three minutes on a GTX 1650), not on a computer without a graphics card. The image engine keeps 5 to 7 GB of RAM while it draws.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.
