Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.2.0_x64-setup.exe`) and run it. If you have 0.1.1 or later, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models.

**Changed since 0.1.9**

Harnesses
- A harness is what the model reads with every request and what it can do: its prompt, its tools, its hooks. Each model has its own, chosen in its row of Settings › Models ("Harness").
- Mango Harness 1 is the one of the earlier versions and stays the default. Mango Harness 2 is new: a Git Bash terminal and a PowerShell one, `read` for PDFs and pictures, `page_look` for the models that see, and hooks that answer the mistakes small models make most often. A path written for Linux (`/home/user/project`, `/workspace`) becomes the project folder, and the model is told so.
- Settings › Agent lists the harnesses and what each one reads and does. "Duplicate" makes one of your own, in which the prompt, the words of the tools, the texts of the hooks and the summary of a long conversation can be changed; "Remove" takes it away.

Conversations
- A long conversation is summarized when it reaches 90% of the context, in the conversation itself and with the same rules for every harness. The summary keeps your messages, the files read and changed and the end of the work.
- An answer has no length limit of its own: it may use all the context left.
- An answer that keeps writing the same text is stopped, one copy of the text is kept, and a line under it says "Answer stopped: it kept repeating the same text."
- Pictures asked together wait their turn: the waiting ones say "Queued", and each counts its seconds from when its own starts.
- In the conversation a summary shows as a line, "Conversation summarized", not as the text written for the model.
- When the model a conversation uses is taken off the computer, another one takes its place and a line above the box says which ("… is no longer on the computer. Using …"); with none left, the box says so and does not send.
- A conversation made, renamed, archived or deleted from the phone or another program shows in the Home at once.
- A message sent the moment a new conversation opens waits for the project to finish loading and goes to the model shown under the box.
- The MCP servers of a project's `.mcp.json` start only after you allow them in the window.
- Web search reads pages up to 5 MB and says when a link is not a page.
- With Mango Harness 1, `ls` of a name with spaces keeps the name whole, PowerShell's errors reach the model in English, and `documents_read` reads text files too (a binary file is refused).

Servers
- Settings › Connections › "Use a server" adds an OpenAI-compatible server: llama-server, LM Studio or a cloud service, with its key if it asks for one. Its models are in the menu under the box beside those of this PC; when the default model is a server's, no local model is loaded at start.
- When a server does not say how much context its models have, the app asks, proposing 32,768 tokens.
- A cloud service with many models (OpenRouter) offers only the models that use tools and have a fixed price, with the price of each; at the first start and on the server's card you choose one from a list with a search, and the default changes only when you pick a model.
- When the model in use on a server has a small context, its card says so, naming the model.
- An address written without `http://` or `https://` works: this PC and its network over http, anything else over https.
- The server's card names its models; "Refresh the list" says in one line what changed (a model gone, a smaller context), and "Remove" asks first. The title bar names a server's model when it is the default.
- LM Studio with models downloaded but none loaded says to load one or to turn on Just-In-Time loading.
- When a server refuses a request or does not answer, the conversation says so in the app's words, followed by the server's own reason.
- The keys are kept in the Windows Credential Manager and never reach the programs the model runs.

Team
- Turning the Team off, removing the key or restarting the app stops the dev and the cloud agents at once, and the conversation says "Team stopped".
- The cards of the Team's tools say what was done ("Asked the dev", "Started an agent"). What the dev or an agent writes to the manager is a line, "The dev wrote to the manager", with the beginning of the message; a click opens all of it, formatted like a message.
- A key OpenRouter refuses is not saved.

Your computer
- The processor's integrated graphics can run the models on the PC's memory: turn it on with "Use for the models" in Settings › Computer. It shows the memory the models can use ("8 GB (shared with the RAM)") and never adds to a dedicated card. When the model does not fit or the start does not hold, it starts once on the processor and a line says so. Pictures go where the models go.
- With one graphics card, or none, a model offers the automatic choice and the processor, not "All cards".
- Git for Windows comes with Mango Code: the terminal of Mango Harness 2 uses it, and every project becomes a git repository also on a PC without Git. The installer is larger because of it (about 157 MB).
- A model file of your own, added as the only model on the computer, starts by itself and answers the first conversation.
- A download that fails for the network starts again by itself, up to three times.
- Dates in the app follow its language ("October 26, 2026").
- The line under the first answer of a conversation counts the system prompt read for it.

For programs that use Mango Code
- External servers: `servers()` in the client, models named `server-<n>/<model>`.
- No request carries `max_tokens`. An answer cut because the context was full ends with `finish: "context"`, and the conversation is summarized; one stopped for repeating itself is taken up with `metadata.resume: "repeat"`.
- A request whose system prompt was read from disk carries `X-Mango-Prefix-Read` with the engine's timings of that reading.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- Pictures on integrated graphics, and the memory reading of AMD and Intel dedicated cards, were not tried on a real computer: if you have one, tell us how it goes.
- Gemma 2 and 3, Mistral v0.3 and Mixtral refuse, with their own conversation format, every conversation in which a tool was used: they do not work as agents.
- The first conversation with a model reads its system prompt and writes a file of 0.3 to 2 GB in the app's data.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.
