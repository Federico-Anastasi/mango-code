Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.5_x64-setup.exe`) and run it. If you have 0.1.1, 0.1.2 or 0.1.4, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models.

**Changed since 0.1.4**

Pictures
- The box of a conversation has two sides, "Text" and "Picture". On "Picture" you describe a picture and the app makes it on your computer, with a model that makes images: Z-Image Turbo (the default) or FLUX.2 klein 4B, both Apache-2.0. Three formats (square, portrait, landscape) and two sizes.
- A picture is a turn of the conversation: it shows while it is drawn, it is saved in the folder `images` of the project (`immagini` with the app in Italian) under a name taken from your words, and "Again" draws it once more.
- A model that writes turns your words into the description the image model draws best. The description is under the picture and can be corrected. In the settings the rewriting can be turned off, and the model that rewrites chosen.
- The model that writes can make a picture by itself while it works. The first time it asks, saying what it will draw.
- Settings, Models: the models that make images have their own group. They download, pause and are removed like the others, and one of them is the default.
- The image engine is stable-diffusion.cpp, downloaded with the first of these models. While a picture is drawn the model that writes lends it the graphics card, and takes it back afterwards.
- Another program can ask for a picture with the client in `integration/client`.
- The agent draws with an image model that is on the computer, whichever it is. With none, the conversation says "No model that draws is on this computer" and offers "Download a model".
- Several pictures asked together are drawn one after the other, without giving the graphics card back in between.

The agent with small models
- A page the agent wrote opens in the panel from its file: the app serves the folder of the page, so a site with several pages works as on the web and the agent starts no server of its own.
- A small model writes paths the Unix way (`/home/user/site/index.html`): such a path now names the file in the project, and the model is told so.
- Its bash habits in PowerShell (`ls -la`, `rm -rf`, `mkdir -p`, `2>/dev/null`, `| grep`, `| head`, `/c/Users/...`) are run as what they mean instead of failing.
- A file too long for one answer no longer stops the work: the model is told to write the first part and add the rest.
- An answer that goes on with blank lines is cut, and the model is asked to go on from where it was.

Models
- A GGUF file of yours that is the file of a model of the catalog is that model: one entry in the list, with the catalog's settings, run from your file, which is never downloaded again nor deleted. A conversation that used the old entry starts again from the default model.

Look
- The whole interface is redrawn: one ground, the same colours and typefaces everywhere, one family of icons, every tool of the agent in a bordered row.
- The theme follows Windows until you choose one.
- The start page has a bar that advances at each stage.

Fixed
- A file the agent wrote outside the project opens from its card in the conversation.
- The list of the models in the settings could stay empty until the app was started again.
- A model made of several files could fill the disk and stop halfway: the room is now checked for the whole model before the download starts.

For programs that use Mango Code
- The engine manager listens on `127.0.0.1:47080`, no longer on 8080, a port development servers take first. A program that reads `service.json`, or uses the client in `integration/client`, needs no change; one with the port written in needs the new one.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- Pictures were tried on NVIDIA cards of 8 GB (10 to 20 seconds a picture on an RTX 3060 Ti) and of 4 GB (one to three minutes on a GTX 1650), not on a computer without a graphics card. The image engine keeps 5 to 7 GB of RAM while it draws.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.
