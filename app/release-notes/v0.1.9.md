Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.9_x64-setup.exe`) and run it. If you have 0.1.1 or later, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models.

**Changed since 0.1.8**

Models you add
- A model whose conversation format wants the system message only at the beginning (such as a Qwen3.5 fine-tune) stopped at the first request with "System message must be at the beginning". Every request now has one system message and the plainest shape a format accepts, the same for every model.
- Adding a model checks it with the requests Mango Code really sends (the first one, the one after a tool, the one with reasoning) and says which one its format refuses. It reads from the file whether the model reasons and, for a mixture of experts, how much of it is read for each token; a model with less context than the agent needs says so.
- The catalog's models run with the conversation format in their own file. Qwen3.5 keeps one line changed so that the reasoning of past turns stays in the history (otherwise the engine reads the last turn again at every message); a Qwen3.5 you add with the same original format gets it too.

Reasoning and the conversation
- A pill beside the model under the box chooses the reasoning, with the choices the model's format offers: Off and On, or Off, Low, Medium and High. The Team's model has Low, Medium and High; a model that does not reason shows none.
- The conversation's header names its project ("No project" without one); the title stays in the tab, and its tooltip says "project · title".

Your computer
- The memory in use on AMD and Intel cards is read too, not only on NVIDIA ones: a model is placed knowing what other programs hold. When it cannot be read, the model starts anyway and a line above the box says so.
- An engine downloaded for a card (CUDA or Vulkan) must see one before it is installed (all but `toq`, which cannot list them): with a graphics driver that has no Vulkan the app says so, instead of running on the processor without telling.
- A choice made while a model loads (the reasoning, or anything in Settings › Models) is applied at once: before, the window waited until the engine had finished reading the model's file, tens of seconds from a mechanical disk.

Libraries
- The agent speaks only to OpenAI-compatible endpoints: the local engine and OpenRouter for the Team. The other cloud providers are gone from it.

For programs that use Mango Code
- A conversation request has one system message: `X-Mango-Stable-Prompt` counts its bytes that come before the working folder and the date.
- The engine manager sends every conversation request with `chat_template_kwargs.preserve_thinking: true`; a format that does not read it ignores it.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- The memory reading of AMD and Intel cards, and integrated graphics used as a graphics card, were not tried on a real computer: if you have one, tell us how it goes.
- Gemma 2 and 3, Mistral v0.3 and Mixtral refuse, with their own conversation format, every conversation in which a tool was used: they do not work as agents.
- The first conversation with a model reads its system prompt and writes a file of 0.3 to 2 GB in the app's data.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.
