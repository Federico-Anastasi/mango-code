Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.4_x64-setup.exe`) and run it. If you have 0.1.1 or 0.1.2, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models. If an earlier version never opened on your PC, install this one by hand: the automatic update needs an app that starts.

There is no 0.1.3 release: its build stopped on one of its own tests, before the installer was made.

**Changed since 0.1.2**

Starting the app
- The app opens on the Home at once, never on the last conversation. The default model loads in the background; its name and what it is doing are in the top bar, on every screen.
- The model can be changed without waiting: a load in progress stops and the new model starts.
- A message sent before the model is ready waits and leaves by itself when it is. Closing the app meanwhile puts it back in the box.
- First start: the Home says what it found on the computer and proposes one model with one button, or a list to choose more than one. The app can be used while the model downloads.
- If the default model does not start, the app says why and offers a model that fits, for that time. If another program is using the memory of a graphics card, it says which card and how much.
- Fixed: the app did not start on a PC with a graphics card too small to run a model (issue #2).

Settings
- One page with six sections (Models, Computer, Agent, Connections, General, Help) and a search that finds every setting. The page "Models and engine" is gone.
- For each model: where it runs (automatic, one card, all cards, processor, cards chosen by name), how much conversation it remembers, the style of its answers, whether it reasons.
- For the computer: graphics cards to leave out of the models.
- "Another model": a model from a Hugging Face link or a GGUF file on the disk.
- Models download in the background, can be paused and resumed, and show in the menu of the top bar.
- One switch for each MCP server; the automatic update can be turned off.

Conversations
- Search inside a conversation, with Ctrl+F or the lens.
- An answer that comes back empty says so and offers "Retry".
- Pages the agent opens go in the panel of the app; your own Chrome is used only when you ask for it, and never in place of a tab you have open. "Open" on an `.html` file opens it in the panel.
- Programs the agent leaves running are listed in the conversation that started them, with "Stop". They stay on until you quit Mango Code; closing the window with X keeps the app in the tray, and says so the first time.
- The app's own keyboard shortcuts and its terminal panel are gone: the system's ones stay (zoom, copy, paste, cut, Enter, Ctrl+F).

Phone
- The new start and the new settings work from the phone. What can only be done on the computer (downloading or removing models, keys, sharing the engine) says so.

Fixed
- Qwen3.6-35B-A3B on NVIDIA cards could stop in the middle of an answer and start over, with messages of some lengths. The `prism` engine is updated; the app downloads the new one by itself at the first start.
- With a GTX 16xx card and the `prism` engine (the tuned set of cards), the downloaded engine read the prompt at about half the speed of the table in the README: 315 tokens per second instead of 551 with Qwen3.6-35B-A3B. The engine now has a build for those cards, which the app picks and downloads by itself.
- Commands run through `cmd` keep accented letters; PowerShell 5.1 errors no longer start with an encoding prefix.
- Dependencies updated.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.
