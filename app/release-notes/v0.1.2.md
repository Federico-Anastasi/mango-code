Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.2_x64-setup.exe`) and run it. If you have 0.1.1, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models. If you have 0.1.0 and it never opened on your PC, install this version by hand: the automatic update needs an app that starts.

**Changed since 0.1.1**
- Fixed: with Windows' text size above 100% (Settings, Accessibility), the window reopened at a different zoom from the one you left it at. The zoom you set now stays. If you had changed it before this update, set it once more.
- Ctrl + mouse wheel and Ctrl+ / Ctrl- / Ctrl+0 also zoom the page in the preview panel, by itself: the chat keeps its own zoom.
- The preview panel is a card with rounded corners, like the chat next to it.
- The phone and tablet sizes of the preview show the page on a phone or a tablet, whole, instead of a strip as tall as the panel.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.

**Engines in this release** (unchanged since 0.1.0)
- llama.cpp b12110 (official builds)
- [mango-prism](https://github.com/Federico-Anastasi/mango-prism/releases/tag/prism-b10709-9a9394a) `prism-b10709-9a9394a`
- [mango-toq](https://github.com/Federico-Anastasi/mango-toq/releases/tag/toq-35e7256) `toq-35e7256`

Please report problems with "Report a problem" in the app, or in the Issues with your graphics cards, processor and memory and what happened.
