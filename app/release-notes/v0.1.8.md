Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.8_x64-setup.exe`) and run it. If you have 0.1.1 or later, the app offers this version by itself at the next start, and it installs over it keeping your conversations and models.

**Changed since 0.1.7**

Models and speed
- The system prompt of a model is read once and kept on disk: a new conversation, another project, the next day or a restart start from it in about a second, instead of reading it again (tens of seconds on a processor). The files stay within 6 GB and go after a day without use.
- The context is told in tokens. It can be 32K, 64K, 128K, 256K up to what fits, or a value of your own in tokens (the + and − move by 4096), up to the model's maximum: the automatic choice is no longer held at 128K.
- The style of the answers shows its six values (temperature, top_p, top_k, min_p, presence and repetition penalty), and each can be changed without reloading the model.
- An answer cut because it reached the length limit goes on once by itself; if it is cut again, a line says so with "Continue".
- A model that runs on the processor of a computer with an NVIDIA card uses the engine built for the processor (a 25 MB download the first time): the card's engine could close while it read a prompt.

Your computer
- The models folder can be chosen in Settings › Computer: the models already downloaded move there, without downloading them again. One model can also be put in a folder of its own.
- Mango Code starts also when another program, such as Kilo Code or opencode, uses port 4096. What the interface remembers (open projects, preferences, drafts) is kept by the app on disk.

Fixed
- The Preview panel stays visible under a menu that does not reach it, and under one that does it shows a picture of the page instead of an empty space.
- The Preview panel shows the new version of a page as soon as the model changes it, without "Reload".
- A skill added to a project while the app is open is ready without restarting: a new conversation lists it, an open conversation is told of it with the next message, and it is in the "/" menu and in the settings.
- A folder is one project however its path is written; the duplicates already saved are merged.
- A page of the computer seen from the phone reaches the servers of the computer on `localhost` and `127.0.0.1`, except those of Mango Code itself.
- The models folder keeps being watched after it is deleted, renamed or on a disk that comes back.
- The programs the agent starts end also when the app is closed by force.

Libraries
- The agent carries only the local engine, OpenAI-compatible endpoints, Anthropic and OpenRouter: no subscription logins and no provider-specific plugins.

For programs that use Mango Code
- A conversation request may say with `X-Mango-Stable-Prompt` how many bytes of its last system message come before the working folder and the date: the engine keeps that part on disk.
- The manager's log has the events `prefix` and `slot files`.

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a general plan that works but is not optimized.
- The first conversation with a model reads its system prompt and writes a file of 0.3 to 2 GB in the app's data.
- Integrated graphics used as a graphics card was not tried on a real computer: if you have one, tell us how it goes.
- Small models (Qwen3.5-2B) can misread a short first message and answer something unrelated: ask again.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6.
