Third public pre-release, the first built and signed by GitHub Actions. Windows 10 or 11, 64-bit only.

**Install:** download the installer below (`Mango.Code_0.1.0-rc.3_x64-setup.exe`) and run it. It installs over rc1 and
rc2 and keeps your conversations and models. At first run the app looks at your graphics cards, processor and memory,
proposes the models that fit, and downloads the matching engine and the models you pick.

**Changed since rc2**
- Automatic updates: once per start the app looks for a newer release, downloads it in the background and offers
  "Install and restart" (a notice, a button in the title bar, Settings > Help). Updates are signed and checked before
  they install. Pre-releases are not offered: from this version on, you get 0.1.0 by yourself when it is out.
- "Report a problem" (Settings > Help and the error pages) sends the logs, the PC details and, if you leave the switch
  on, a screenshot of the window, in one click. Your user name, PC name, emails, network addresses and keys are
  removed before sending.
- A conversation no longer goes blank while a file card waits for an answer.
- On a narrow window (laptops with display scaling) the browser panel covers the chat instead of staying hidden.
- Qwen3.8-27B-TOQ-v1 stays in the list for whoever chooses it, but it is never preselected nor marked fastest.
- The installer carries the licenses (`resources\licenses`).

**What to expect**
- The installer is not signed with a Windows certificate: SmartScreen may ask you to confirm ("More info" → "Run
  anyway").
- The app is tuned only for one set of cards (RTX 3060 Ti + GTX 1080 + GTX 1660 SUPER); on other hardware it uses a
  general plan that works but is not optimized.
- Qwen3.8-27B-TOQ-v1 needs the `toq` engine, downloaded automatically. As an agent it is less reliable than Qwen3.6:
  in our tests it sometimes ignored the web search tool.

**Engines in this release** (unchanged since rc2)
- llama.cpp b12110 (official builds)
- [mango-prism](https://github.com/Federico-Anastasi/mango-prism/releases/tag/prism-b10709-9a9394a) `prism-b10709-9a9394a`
- [mango-toq](https://github.com/Federico-Anastasi/mango-toq/releases/tag/toq-35e7256) `toq-35e7256`

Please report problems with "Report a problem" in the app, or in the Issues with your graphics cards, processor and
memory and what happened.
