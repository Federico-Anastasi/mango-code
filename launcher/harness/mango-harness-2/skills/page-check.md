# Page check
1. `page_view` the file you wrote.
2. Read what came back. Is every piece of the request on the page? Is there an error in the console?
3. If the page does something (a button, a form, a menu), try it with `page_act` and read the page again.
4. Something missing or an error: `edit` the file, then `page_view` again. Repeat until it comes back clean.
5. Tell the user in one or two lines what the page does and what you checked.

You cannot see colours or images: say so if the user asks about the look, and describe what the code sets.
