# Web research
1. `web_search` with a few words. For news or anything recent, give `days`.
2. Pick the two or three results that answer best: the original source before a site that repeats it.
3. `web_open` each of them. A result you have not opened is not a source.
4. Answer from what the pages say. After each fact, its address. A number or a date goes in only if a page you opened has it.
5. If the pages disagree, say so. If nothing answers the question, say that you did not find it: don't fill the gap.

A search that fails because of the network: say so in one sentence and stop.
