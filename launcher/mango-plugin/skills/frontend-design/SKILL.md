# Frontend Design

Make deliberate choices of palette, typography and layout that belong to this brief, and take one aesthetic risk you can justify. A page that could be for any subject is a template.

## Before you design
- If the brief doesn't say, pin it down: one concrete subject, its audience, the page's single job. Say what you chose.
- The subject's own world (its materials, instruments, vocabulary) is where distinctive choices come from. Use the brief's real content throughout.
- If the brief fixes a look, follow it exactly. Where it leaves an axis free, avoid the three defaults that appear for every subject: a warm cream page with a high-contrast serif and a terracotta accent; near-black with one acid-green or vermilion accent; a broadsheet of hairline rules and square corners.

## Plan, then build
Write a short plan first: **color** (4-6 named hex values), **type** (a display face used with restraint, a body face, a utility face if needed), **layout** (one sentence or an ASCII sketch), **signature** (the one element the page is remembered by). Check each part against the brief: if it is what you would produce for any similar page, change it. Then build following the plan, deriving every color and type choice from it.

## Principles
- The hero is a thesis: open with the most characteristic thing in the subject's world (a headline, an image, a live demo). A big number with a small label and a gradient accent is the template answer.
- Typography carries the personality: pair the faces on purpose, set a clear scale with intentional weights and spacing.
- Structure encodes something true: numbered markers (01 / 02 / 03) only for a real sequence.
- Motion where it serves the subject: one orchestrated moment (page load, a reveal) beats scattered effects. Less is often more.
- Match complexity to the vision: maximalism needs elaborate execution, minimalism needs precision in spacing and detail.
- Spend your boldness in one place; keep the rest quiet; cut decoration that doesn't serve the brief.
- Quality floor, without announcing it: responsive down to a phone, visible keyboard focus, reduced motion respected.
- Watch the CSS specificity: type selectors and class selectors easily cancel each other's padding and margins.

## Words in the design
Copy is design material. Write from the user's side of the screen: name things by what people control, active voice, "Save changes" not "Submit", the same name for an action through the whole flow. An error says what went wrong and how to fix it; an empty screen invites to act. Plain verbs, sentence case, no filler.

## Check
Open the page in the browser panel and look at it (see the browsing instructions); fix what you see, don't assume.
